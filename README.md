### Overview

**sunmeat.dev** is my personal portfolio and a living showcase of the things I build. It brings together my work in full-stack development, native Android, education, and independent product experiments in one carefully designed space.

The interface combines a dark, terminal-inspired aesthetic with a clear responsive layout. The repository is also documented to make its structure, design decisions, maintenance, and deployment easier to understand.

### What you'll find

- **A professional profile:** background, experience, skills, and contact links.
- **Android applications:** published apps with links to their Google Play listings.
- **Web projects:** live websites and selected independent experiments.
- **A technical overview:** languages, frameworks, platforms, and development tools.
- **An interactive profile card:** comments powered by Firebase / Firestore.
- **A responsive interface:** layouts designed for mobile, tablet, and desktop.
- **Discoverability and insights:** SEO metadata, Open Graph previews, structured data, and Vercel Web Analytics.

### Run locally

**Requirements:** a recent version of Node.js and npm.

```bash
git clone https://github.com/sunmeat/me.git
cd me
npm install
npm run dev
```

Production build and preview:

```bash
npm run build
npm run preview
```

Run the code-quality checks:

```bash
npm run lint
```

Some interactive features require Firebase configuration. See [`env.example`](env.example) and the deployment guide before configuring a local environment. Never commit real credentials or private environment files.

### Project structure

```text
me/
├── .github/       # Community files, templates, and automation
├── docs/          # Project and maintenance documentation
├── public/        # Static assets and preview images
├── src/
│   ├── components/  # Page sections and reusable UI
│   ├── App.jsx      # Main page composition
│   ├── data.js      # Portfolio content and profile data
│   ├── firebase.js  # Firebase setup
│   ├── App.css      # Styles and design tokens
│   └── main.jsx     # Application entry point
├── index.html     # HTML shell and metadata
├── package.json   # Scripts and dependencies
└── vite.config.js # Vite configuration
```

Most portfolio copy, project lists, skills, and profile statistics are maintained in `src/data.js`. Reusable page sections live in `src/components/`.


# Governance · Управление проектом

This document describes how decisions and contributions are handled in **sunmeat/me**, the personal portfolio of [@sunmeat](https://github.com/sunmeat).

Этот документ описывает принятие решений и работу с вкладом участников в **sunmeat/me**, персональном портфолио [@sunmeat](https://github.com/sunmeat).

---

## 🇬🇧 English

### Project ownership

The repository is maintained by **Oleksandr Zahoruiko** ([ @sunmeat ](https://github.com/sunmeat)). The maintainer is responsible for the project's direction, published content, visual identity, releases, and acceptance of changes.

### Decision-making

- The maintainer makes the final decision on changes to the portfolio.
- Substantial changes to the design, personal presentation, or project scope should be discussed before implementation.
- Decisions prioritize accuracy, accessibility, usability, maintainability, performance, and consistency with the project's purpose.
- Review and merge are at the maintainer's discretion. A contribution does not guarantee acceptance.

### Contributions and review

Please follow [CONTRIBUTING.md](CONTRIBUTING.md), the [Code of Conduct](CODE_OF_CONDUCT.md), and the relevant pull request template. The repository's [CODEOWNERS](CODEOWNERS) file identifies the default reviewer/owner.

### Security

Report suspected vulnerabilities privately according to [SECURITY.md](SECURITY.md). Do not publish exploit details or sensitive information in public discussions.

### Changes to this policy

This governance document may be updated as the project evolves. The version in the default branch is the current reference.

## 🇷🇺 Русский

### Владелец проекта

Репозиторий сопровождает **Александр Загоруйко** ([ @sunmeat ](https://github.com/sunmeat)). Сопровождающий отвечает за направление развития проекта, опубликованный контент, визуальную идентичность, релизы и принятие изменений.

### Принятие решений

- Окончательное решение по изменениям портфолио принимает сопровождающий проекта.
- Существенные изменения дизайна, личной самопрезентации или назначения проекта следует предварительно обсудить.
- Приоритеты: достоверность, доступность, удобство, сопровождаемость, производительность и соответствие назначению проекта.
- Проверка и слияние изменений остаются на усмотрение сопровождающего. Отправка вклада не гарантирует его принятие.

### Вклад и ревью

Следуйте руководству [CONTRIBUTING.md](CONTRIBUTING.md), [Кодексу поведения](CODE_OF_CONDUCT.md) и соответствующему шаблону pull request. Файл [CODEOWNERS](CODEOWNERS) указывает владельца/ответственного за ревью по умолчанию.

### Безопасность

О предполагаемых уязвимостях сообщайте конфиденциально в соответствии с [SECURITY.md](SECURITY.md). Не публикуйте подробности эксплуатации или чувствительные данные в открытых обсуждениях.

### Изменение правил

По мере развития проекта этот документ может обновляться. Актуальной считается версия из основной ветки репозитория.
